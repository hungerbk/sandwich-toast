# 테스트

- `npm test`: 테스트를 한 번 실행합니다(CI에서도 동일한 명령 사용).
- `npm run test:watch`: 변경 시 테스트를 다시 실행합니다.
- `npm run typecheck`: 제품 코드와 테스트 코드의 타입을 검사합니다.

현재 store와 toast API의 기본값·옵션·삭제 계약을 검증합니다. jsdom은 브라우저 DOM을 모사하며 실제 레이아웃이나 스크린리더를 검증하지 않습니다. 실제 낭독, 이미지 품질, 화면 가장자리 잘림, 글자 확대는 브라우저에서 별도로 확인해야 합니다.

타이머·컴포넌트·SSR 회귀와 CI 구성은 #43의 다음 작업 단위에서 추가합니다.
